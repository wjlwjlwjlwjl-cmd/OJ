# OJ平台项目规格说明书

## 项目概述
构建一个仿LeetCode的在线评测（OJ）系统，主要用于教学用途，支持多语言代码提交与自动评测。

## 业务目标
- **主要用户群体**：教学使用，面向学生学习编程和算法
- **规模预估**：小规模使用（几十个用户，每天几百次提交）
- **成功标准**：为教学提供稳定的编程练习平台，支持常见算法题目的评测

## 技术栈
- **后端语言**：C++
- **Web框架**：cpp-httplib
- **前端技术**：原生HTML + CSS + JavaScript
- **数据库**：MySQL
- **部署环境**：本地服务器

## 系统架构

### 整体架构
```
[前端界面] -> [HTTP API层] -> [业务逻辑层] -> [评测引擎] -> [安全沙箱]
     |                           |              |           |
[用户交互]                   [题目管理]    [编译运行]  [资源限制]
     |                           |              |           |
[题目浏览]                   [用户管理]    [结果解析]  [安全隔离]
```

### 核心组件
1. **Web服务器**：基于cpp-httplib实现HTTP请求处理
2. **题目管理系统**：管理题目信息、测试用例等
3. **用户管理系统**：处理用户注册、登录、权限等
4. **评测引擎**：编译、运行、评测用户提交的代码
5. **安全沙箱**：限制用户代码的资源使用和系统访问

## 功能需求

### 用户功能
- 用户注册/登录
- 题目浏览与搜索
- 代码在线编辑（含语法高亮、自动缩进）
- 代码提交与评测
- 提交历史查看
- 评测结果反馈

### 管理员功能
- 题目创建与编辑
- 测试用例管理
- 用户管理
- 系统监控

## 非功能需求

### 性能要求
- 页面响应时间 < 2秒
- 评测结果返回时间 < 5秒
- 支持并发用户数：50-100人

### 安全要求
- 用户代码执行需在沙箱环境中
- 限制CPU时间、内存使用
- 防止恶意系统调用
- 输入输出文件路径限制

### 可靠性要求
- 系统可用性 > 95%
- 支持7x24小时运行
- 异常情况下的错误恢复机制

## 多语言支持
- C/C++ (gcc/g++)
- Java (javac/java)
- Python (python3)
- 更多语言可根据教学需求添加

## 数据库设计要点
- 用户表：存储用户信息、权限等
- 题目表：存储题目内容、难度、标签等
- 提交记录表：存储用户提交的代码、评测结果等
- 测试用例表：存储题目的输入输出测试数据

## 安全沙箱实现
- 使用进程级资源限制（setrlimit）
- 时间和内存限制
- 文件系统访问控制
- 网络访问限制

## 验收标准

### 功能验收
1. 用户能够正常注册、登录
2. 能够浏览和搜索题目
3. 代码编辑器具备语法高亮和自动缩进
4. 代码提交后能够正确评测并返回结果
5. 支持至少3种编程语言的评测

### 性能验收
1. 在模拟50并发用户下，系统响应正常
2. 单个评测任务在规定时间内完成
3. 系统长时间运行无明显性能下降

### 安全验收
1. 恶意代码（无限循环、内存溢出）不会影响系统稳定性
2. 用户无法访问非授权资源
3. 评测环境相互隔离
